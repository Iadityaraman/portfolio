# ADITYA.OS v1.0.4 — DEVELOPER UNIVERSE

A futuristic, Awwwards-level interactive developer portfolio crafted for **Aditya Raman** (First-Year B.Tech Computer Science student at Newton School of Technology, Rishihood University).

---

## ⚡ Visual & Interactive Features
- **Theme:** Deep Void Black (`#050505`) with Cyberpunk Electric Green (`#00ff66`) accents and clean glassmorphism.
- **Cinematic Opening:** Simulated `ADITYA.OS` kernel boot sequence with live typing logs, telemetry progress, and the `[ ENTER MY WORLD ]` unlock screen.
- **Interactive 3D Cyber Core:** A real-time 3D wireframe polyhedron rendered on an HTML5 `<canvas>` that rotates and responds dynamically to mouse movement.
- **Real Working CLI Terminal:** Type commands at `aditya@portfolio:~$` (`help`, `about`, `skills`, `journey`, `projects`, `philosophy`, `clear`, `matrix`). Features command history (↑ / ↓ arrows) and tab autocomplete.
- **1% Better Every Day Contribution Matrix:** 52-week GitHub-inspired activity calendar with interactive hover tooltips displaying date, hours coded, and concepts studied.
- **Interactive Skill Neural Map:** Live status badges (`CURRENTLY LEARNING` / `EXPLORING`) for Python, Terminal, Git, and GitHub.
- **Audio Synthesizer:** High-tech UI sounds generated in real-time via the Web Audio API (with a mute toggle in the top-right).
- **Custom Cyber Cursor:** Dynamic trailing glow cursor with magnetic hover detection.
